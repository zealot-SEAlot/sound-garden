# 🌙 Sound Garden

A little musical toy for your browser. Plant glowing flowers on a night sky, and a moonbeam sweeps across to play them on a loop.

**▶ Play it: https://nathanflorencecasas-create.github.io/sound-garden/**

## How to play

- **Click** anywhere to plant a flower. Higher flowers sing higher notes.
- **Drag** a flower to move it. Drag it off the edge (or right-click it) to pull it up.
- **Space** pauses and resumes the loop.
- Change the **loop length** and **scale** in the bar at the bottom, or hit **✨ Surprise** for a random garden.

Your garden is saved in your browser, so it's still there when you come back.

## Run it locally

No install or build step. Download `index.html` and open it in any modern browser (turn your sound on).

## Built with

Plain HTML, CSS, and JavaScript: the Canvas API for the visuals and the Web Audio API for the sound.
